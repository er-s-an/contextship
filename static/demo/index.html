ContextShip

A Forge-installable Rovo agent that turns ticket / PR / release context into executable next steps — so “almost ready to ship” becomes a clear checklist.

View on GitHub See sample checklist

The problem

Shipping software is rarely blocked by a single missing field. It is blocked by scattered context: an open PR without approval, a blocker still In Progress, a QA subtask unfinished, and comments that only half the team has read. People waste time reconstructing “what is left?” instead of executing.

How ContextShip helps

  1. 1
    Install the Forge app
    Rovo agent + skills + actions land in your Atlassian site.
  2. 2
    Ask about a ticket
    Agent pulls issue fields, links, comments, and linked PRs via Forge actions.
  3. 3
    Get a ship checklist
    Blocked / ready signals become concrete next steps — not another wall of text.

Sample story — SHIP-42

Flaky payment webhook retries. Open PR without approval, blocked by SHIP-39, QA subtask still in progress.

Try locally (no Atlassian login)

git clone https://github.com/er-s-an/contextship.git
cd contextship
npm install
npm run demo          # SHIP-42 → blocked checklist
npm run demo SHIP-7   # healthier docs-only path
npm test

Forge install (needs Atlassian account)

npm install -g @forge/cli@latest
forge login
forge register   # replaces placeholder app id
forge deploy
forge install    # or: forge install --demo-site
